## Vision

### 10x Check
날씨 기반 출퇴근 추천을 넘어, 하이브리드 근무자의 "오늘 출근해야 하나?"라는 매일의 의사결정을 완전히 자동화하는 개인 비서. 위젯 한 번 보면 답이 나오고, 아침 알림이 행동을 바꾸고, 월말에는 "나는 비 오는 날 8번 피했다"는 만족감을 준다.

### Platonic Ideal
앱을 열 필요 없이 홈 화면 위젯에서 오늘의 추천이 보이고, 아침 출발 전 알림이 실행 가능한 정보를 전달하며, 저녁 알림이 오늘을 기록하고 내일을 예고한다. 반차 추천이 "비 피하면서 할당량 채우기"라는 독특한 가치를 제공한다.

## Accepted Scope (added to this plan)

### E1: WidgetKit 홈스크린 위젯
- Small 위젯: 원형 프로그레스 링('8/12' 중앙 텍스트) + 추천 라벨(출근/재택/오후출근) 하단 표시
- App Groups를 통한 데이터 공유 (메인 앱이 공유 컨테이너에 추천 결과 기록 → 위젯이 읽기 전용으로 소비)
- 위젯은 Open-Meteo를 직접 호출하지 않음 — 메인 앱 캐시 데이터만 사용
- TimelineProvider: `.atEnd` 정책, 메인 앱 데이터 갱신 시 `WidgetCenter.shared.reloadAllTimelines()` 호출
- 위젯 데이터는 메인 앱 실행에 의존하므로, 24시간 이상 앱 미실행 시 stale 데이터 표시 가능. 위젯에 '마지막 업데이트' 시간 표시로 사용자에게 명시
- 구현 우선순위: P3 (코어 기능 완성 후)
- **Risk:** SwiftData + App Groups는 공유 ModelContainer URL 설정 필요. P1 완료 전 별도 브랜치에서 PoC 검증. 실패 시 fallback: `UserDefaults(suiteName:)`으로 추천 결과만 공유

### E2: 아침 로컬 알림
- 사용자 설정 departureTime 기준 30분 전에 로컬 알림 발송
- 스케줄링 트리거: 21시 알림 액션 핸들러 **또는 dismiss 핸들러** 또는 앱 foreground 진입 시 아침 알림 등록
- BGAppRefreshTask 미사용 (iOS 실행 보장 없음, 복잡도 대비 가치 낮음). 전날 밤 예보 기준으로 확정
- APNs 미사용 — UNUserNotificationCenter 로컬 알림만 (SPEC v1 제약 준수)
- **한계:** 사용자가 전날 앱을 열지 않고 21시 알림도 무시하면 아침 알림이 스케줄링되지 않음. best-effort 기능
- **Dismiss 한계 (Codex #3):** iOS는 알림을 배너에서 밀어 없애면 dismiss callback을 전달하지 않음. `UNNotificationDismissActionIdentifier`는 명시적 dismiss(알림 센터에서 X 탭) 시에만 동작. 따라서 이 안전장치도 best-effort

### E3: 월간 요약
- 인앱 화면으로 구현: 다음 달 1일 이후 대시보드에 이전 달 요약 카드 표시
- 기존 per-month `days` 레코드에서 파생 (officeDone, 평균 통근 점수)
- "비 피한 횟수" 산출: 체크인 시점에 해당 일의 날씨 점수를 per-day 레코드에 스냅샷으로 저장 (**P1b에서 스냅샷 저장 시작** — P4가 아닌)
- **표현 정정 (Codex #8):** "비를 피한 횟수"는 실제 강우가 아닌 예보 기반. UI 문구를 "비 예보일에 재택한 횟수"로 변경
- 구현 우선순위: P4 (화면만. 스냅샷 저장은 P1b)

### E4: l10n
- ja + ko + en (String Catalogs), en은 ja/ko와 완전 문자열 동등
- SPEC은 ja+ko만 명시 — 이 Plan에서 en 추가 (App Store 노출 확대)

### E5: Weather API
- Open-Meteo 확정 — 시간별 precipitation_probability, precipitation, snowfall, wind_speed_10m, temperature_2m
- **API 계약 (Codex #15):**
  - 풍속 단위: `wind_speed_unit=ms` 파라미터 명시 (기본값 km/h → m/s 변환 필요)
  - precipitation: 직전 1시간 합계값. 통근 시각 매핑 시 이 점 반영
  - timezone: `timezone=auto` 파라미터 명시 (DST 자동 처리)
  - golden test에 단위 파라미터 포함

### E6: 사무실 좌표
- 온보딩에서 집 + 사무실 두 좌표 입력 (MKLocalSearchCompleter → MKLocalSearch로 좌표 획득)
- 아침/낮 구간: 집 좌표 사용, 저녁 퇴근 구간: 사무실 좌표 사용
- 사무실 좌표 미입력 시: 집 좌표로 통일 (기존 동작 유지)

### E7: 미래 예보 비교 엔진
- 기존 SPEC 임계값 `T = 100 × (1 − oRemain/R)`은 1차 필터로 유지
- 추가: 남은 근무일(최대 7일)의 예보를 가져와 오늘 점수의 상대 순위 계산
- 오늘이 남은 날 중 상위 oRemain개 안에 들면 출근 추천 강화, 아니면 재택 추천 강화
- 7일 이후 예보는 정확도 낮으므로 사용하지 않음
- **복잡도 관리:** 순수 함수로 격리, golden test로 검증

## Error & Rescue Registry

| Error | Rescue | User Experience |
|-------|--------|----------------|
| Network unreachable | 캐시 fallback | "오프라인 — 캐시 사용" |
| API 429/500 | 1회 재시도 → 캐시 | 투명 처리 |
| JSON decoding 실패 | 캐시 fallback + 로그 | "데이터 오류 — 캐시 사용" |
| 빈 hourly 배열 | "추천 불가" 표시 | "직접 판단해주세요" |
| nil forecast 시간대 | 전후 시간대 보간 + 배지 | "예보 불완전" 배지 |
| SwiftData 저장 실패 | Alert + 재시도 | "저장 실패, 다시 시도" |
| 중복 체크인 | 덮어쓰기 | 투명 처리 |
| 알림 권한 거부 | 설정 안내 | "알림 권한을 허용해주세요" |
| 알림 64개 한도 | 오래된 것 정리 | 투명 처리 |
| App Groups 미접근 | 위젯 stale 데이터 | "마지막 업데이트" 표시 |
| O 미입력 | 온보딩 리다이렉트 | 온보딩 화면 |
| R == 0 | "근무일 없음" 표시 | 해당 메시지 |
